# Use ChartQA as the sole required benchmark

The required experiment will use [ChartQA](https://github.com/vis-nlp/ChartQA) so the 30–40 hour build can prioritize a complete Version N+1 loop, rigorous evaluation, sponsor integrations, and the live demo. [MathVista](https://huggingface.co/datasets/AI4Math/MathVista) remains a stretch generalization test because making both datasets mandatory would materially increase integration, evaluation, and runtime risk.
