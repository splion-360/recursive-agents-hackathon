# Keep You.com outside the core runtime

ChartQA will remain a Closed-Book Evaluation, so the core runtime will not integrate You.com search or research. Web retrieval is unnecessary for solving the benchmark, introduces contamination risk, and would be a sponsor integration added for positioning rather than a capability the project requires; Crusoe, Nemotron, NemoClaw/OpenShell, and MemMachine remain the natural critical-path integrations.
