# Restrict the primary condition to behavior-card retrieval

The primary memory-distilled condition will retrieve only accepted procedural Behavior Cards; it will never expose raw Reviewed Episodes to the Student, even as a low-confidence fallback. Episodes remain in MemMachine for provenance, consolidation, and visualization, while raw-episode retrieval may be measured only as a separately labeled ablation so the main result cannot be dismissed as example retrieval or answer leakage.
