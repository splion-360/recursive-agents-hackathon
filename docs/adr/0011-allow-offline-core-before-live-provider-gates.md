# Allow the deterministic core before live-provider gates

Provider-independent schemas, pure lifecycle logic, fake adapters, synthetic fixtures, offline integration tests, sanitized replay data, and the replay visualizer may be implemented before Crusoe credits and managed services are available. This exception keeps offline work moving without weakening the experiment gate. Production composition, real model calls, managed MemMachine writes, paid inference, live OpenShell execution, measured Collection, Promotion, and Final Held-Out orchestration remain forbidden until the Crusoe Student, Nemotron Reviewer, Consolidator, MemMachine, and NemoClaw/OpenShell seams each pass their explicit smoke and contract checks. Configuration presence alone is not evidence that a seam passed.
