Revised proposal · 16 October 2026

Can an agent team earn its next operating procedure?

A Nemotron reviewer repairs a smaller visual agent. A Consolidator turns repeated repairs into answer-free Behavior Cards in MemMachine. A promotion gate keeps only versions that measurably help.

Primary theme: Version N+1. Shared Brain is the mechanism. The project proves whether reviewed behavior can remain external, inspectable, reversible, and reusable without weight updates or reviewer calls at deployment.

Decision brief

Build the smallest complete self-improvement loop.

The required build uses one benchmark, four experimental conditions, one operational memory, and one automatic version gate. MathVista, raw-episode retrieval, and weight updates are stretch work.

The product

An agent team that proposes changes to its own reusable procedures and must earn promotion through controlled validation.

The proof

A fresh Student uses an Accepted Version from MemMachine on unseen tasks while the Reviewer is absent and memory writes are disabled.

01 · Hackathon alignment

Version N+1 is the claim. Shared Brain makes it possible.

The system does not keep every generated memory. It proposes, measures, promotes, rejects, and rolls back versions of its operating procedure.

Primary

Version N+1

Reviewed failures become candidate procedures. Only a batch that passes capability and efficiency gates becomes the next Accepted Version.

Mechanism

Shared Brain

MemMachine carries Reviewed Episodes, Behavior Cards, provenance, and version state across roles and fresh Student sessions.

Supporting

Done Means Done

The team defines completion through executable gates. It can reject harmful self-modification and stop without asking a human to curate results.

Judge-facing sentenceThe team is not rewarded for remembering more. It is rewarded only when a candidate memory version improves unseen work without unacceptable regression or cost.
02 · Inspiration and novelty

Harness-Zero moves behavior into weights. This project keeps it inspectable.

Harness-Zero supplies the response-boundary supervision pattern. This proposal changes the transfer medium, modality, update lifecycle, and deployment tradeoff.

Selective upstream reuseThe reviewed Apache-2.0 upstream is pinned at a4a6223. We may adapt its PASS/REPLACE contracts, response-boundary supervision, and H-star-to-Kappa mapping ideas with attribution. We explicitly exclude Harbor, DeepAgents, SFT, benchmark banks, and its single-execute runtime.
03 · Research claim

A falsifiable claim, not a guaranteed success story.

Hypothesis

An Accepted Version will improve paired ChartQA accuracy over the minimal baseline while using fewer calls, tokens, or latency than online Reviewer guidance.

Falsification

The claim fails if memory does not improve accuracy, trigger-irrelevant memory performs similarly, or gains require raw episodes, human curation, or leaked answers.

Valid negative outcomeA candidate that fails promotion and leaves the stronger Accepted Version active still proves the autonomous safety mechanism. It does not prove memory transfer.
04 · Canonical roles

Roles are fixed. Endpoint IDs are configuration.

The build never changes its meaning when account-specific model IDs differ. A smoke test chooses endpoints against explicit capability contracts.

Student

The smallest available Crusoe multimodal model with measurable ChartQA headroom. It acts through the fixed minimal harness.

Reviewer

A Crusoe-hosted Nemotron multimodal model. It consumes frozen Kappa Guidance and accepts or minimally replaces each proposed Student action.

Consolidator

An available Crusoe text model selected for schema reliability. It converts repeated corrections into candidate procedures.

Promotion Gate

Deterministic code compares candidate and accepted versions. It—not an LLM or human—makes the promotion decision.

Evaluator

Official ChartQA normalization plus paired statistical analysis. It never writes memory or supplies task answers.

H-star Analysis Model

An optional calibration-only model may propose one bounded H-star revision. Its endpoint is discovered at the provider gate; regression evidence decides acceptance.

Harness artifacts, not extra agentsH is the fixed Minimal Harness. H-star is a calibration-only optimized reference. Kappa Guidance is the frozen, answer-free artifact adapted from H-star for the Reviewer; Kappa is not a model. The human operator only configures credentials and recovers infrastructure.
05 · Architecture

Supervision becomes a candidate procedure, then must earn promotion.

0 · CalibrateUse the disjoint Harness Calibration Set to derive, hash, and freeze H-star and Kappa.
1 · CollectStudent proposes typed actions on all 40 Collection tasks against one Accepted Version.
2 · ReviewNemotron plus frozen Kappa emits PASS or the smallest valid replacement.
3 · PersistReviewed Episodes enter managed MemMachine with provenance.
4 · ConsolidateOne frozen episode snapshot produces CREATE, REINFORCE, REFINE, or RETIRE deltas.
5 · Screen and freezeDeterministic checks reject contamination before one immutable Candidate Version forms.
6 · PromoteCandidate and Accepted Versions run on all 30 Promotion tasks.
7 · EvaluateThe frozen winner runs C0–C3 once with writes off.
CALIBRATE AND FREEZE KAPPA → COLLECT BATCH → FREEZE SNAPSHOT → CONSOLIDATE → SCREEN → COMPARE → ACCEPT OR REJECT → FINAL C0–C3
Execution BoundaryEvery run_python action executes inside OpenShell under a NemoClaw-managed sandbox. Network is denied and filesystem access is scoped.
06 · MemMachine lifecycle

MemMachine is the only operational improvement substrate.

Agents never retrieve from local telemetry. A JSONL Experiment Trace exists only for metrics, debugging, and visibly labeled replay.

Reviewed Episodes

Collection trajectories, action diffs, tool observations, outcomes, correction reasons, and provenance live in episodic memory.

Behavior Cards

Structured long-term records contain triggers, procedures, verification steps, failure modes, support, confidence, and version metadata.

Version manifests

Immutable manifests list card IDs. An accepted-version record identifies the only version eligible for Student retrieval.

07 · Task suite

ChartQA is required. MathVista is stretch-only.

ChartQA supplies chart images, human-authored questions, known answers, and official relaxed-accuracy logic. Deterministic manifests prevent membership drift.

Harness Calibration Set

Exactly 16. Eight discovery and eight regression items derive H-star and Kappa; they never create Behavior Cards.

Collection Set

Exactly 40. Reviewer-guided episodes may generate one Candidate Version.

Promotion Set

Exactly 30. Validation items accept or reject the candidate and never produce memories.

Final Held-Out Set

Exactly 60. Untouched items run once after the final Accepted Version is frozen.

Primary manifest is fixedThe required run remains 16 / 40 / 30 / 60. Any larger post-hackathon study uses newly declared manifests and cannot replace or retroactively alter the primary evidence.
Manifest ruleUse deterministic hashes, stratify by question and operation type, and assert zero task or image overlap. The final manifest is inaccessible to collection and promotion code.

08 · Experiment design

Four required conditions answer four different objections.

C0 · Minimal baseline

Student, minimal harness, no Reviewer, no memory. This establishes the floor.

C1 · Reviewer-guided ceiling

Reviewer checks every Student action. This estimates transferable benefit and online supervision cost.

C2 · Accepted Version

Fresh Student, accepted Behavior Cards, Reviewer off, writes off. This is the primary result.

C3 · Irrelevant memory

Reviewer off. A predeclared donor pool supplies trigger-mismatched accepted cards, matching C2 card count exactly and token count within 10%.

C3 freeze ruleFreeze the accepted-card donor pool, trigger-mismatch rule, count and token tolerances, and seed 20261016 before final access. After loading answer-free final task inputs, materialize assignments deterministically before any condition executes or scoring reference is loaded. Report C3 unavailable when no honest match exists and disclose the eligible paired population. If empty Accepted v000 remains active, C2 collapses to no-memory behavior and C3 is unavailable; this is a degenerate negative result, not evidence for relevance.

09 · Metrics and controls

Paired outcomes matter more than a decorative leaderboard.

Capability

  • Paired relaxed-accuracy delta
  • Positive and Negative Transfer
  • Gap recovery against C1
  • Accuracy by operation type

Efficiency

  • End-to-end p50 and p95 latency
  • Input and output tokens
  • Model and tool calls
  • Cost per solved task when available

Memory quality

  • Deterministic trigger precision at k
  • No-retrieval rate
  • Compression ratio
  • Duplicate and contradiction rate

Primary analysis

Run every required condition once with lowest-variance decoding and identical token, tool, and step budgets. Report paired bootstrap intervals and McNemar’s exact test.

Robustness evidence

If time permits, repeat all required conditions three times on a frozen 20-item subset and report run-to-run variance.

Leakage target: zeroReject any card containing task IDs, image IDs, answer options, final answers, raw chart values, or copied question text. Preserve only episode IDs as provenance.
10 · Critical-path integrations

Every named integration owns a necessary boundary.

Crusoe

Inference plane

All Student, Reviewer, and Consolidator inference uses Managed Inference. The adapter records endpoint, latency, tokens, retries, and errors.

NVIDIA Nemotron

Privileged Reviewer

The required multimodal Reviewer sees the image, state, proposed action, and frozen Kappa Guidance during calibration, measured Collection, and C1 only.

MemMachine

Operational memory

Managed MemMachine stores every Reviewed Episode, Behavior Card, version manifest, and accepted-version pointer used by agents.

NemoClaw + OpenShell

Execution Boundary

NemoClaw manages the sandbox. OpenShell executes generated Python with explicit time, network, filesystem, and resource policy.

Live execution gateOffline schemas, pure logic, fake adapters, synthetic lifecycle tests, and replay UI may be built before credits arrive. Production composition, managed writes, paid calls, and measured orchestration remain blocked until the Student, Nemotron Reviewer, Consolidator, MemMachine, and OpenShell seams each pass direct contract evidence. Configuration alone is not evidence.

13 · Definition of Done

Completion is executable and independent of a positive hypothesis.

Required

  • All four critical integrations pass smoke tests
  • One end-to-end collection and consolidation cycle
  • Automatic candidate screening and promotion
  • Four required final conditions
  • Custom live or honest replay demo
  • Public repository and accessible one-minute video

Not required

  • A promoted candidate
  • A positive final accuracy delta
  • MathVista
  • Raw-episode ablation
  • Repeated full benchmark runs
  • Fine-tuning
Failure storyIf a candidate harms capability or efficiency, show the automatic rejection, unchanged Accepted Version, and exact failing gate. That is successful governance, not successful transfer.

15 · Implementation contract

Defaults are explicit; access-dependent values are discovered once.

Minimal action space

  • inspect_image(region?)
  • crop(x0,y0,x1,y1)
  • run_python(code)
  • final_answer(answer)

Starting limit: eight total actions and two Python calls per task.

Starting runtime policy

  • Lowest supported temperature
  • Fixed prompt and token budgets
  • Five-second Python timeout
  • No OpenShell network access
  • No writes outside task workspace
  • One structured-output repair attempt

Behavior Card schema

{ "card_id": "sha256-of-canonical-card", "version_id": "candidate-v001", "status": "candidate | accepted | rejected", "trigger": { "benchmark": "chartqa", "question_type": "lookup | comparison | arithmetic | trend", "operation": "string", "visual_cues": ["string"] }, "procedure": ["ordered, answer-free step"], "verification": ["deterministic check"], "failure_modes": ["known misuse"], "support_episode_ids": ["memmachine-id"], "support_count": 2, "confidence": 0.0, "content_hash": "sha256" }

Retrieval defaults

Filter by benchmark, question type, and operation. Use top_k=3. Calibrate one score threshold on Collection data, then freeze it.

If no card passes, use no memory. Never force retrieval.

Forbidden card content

Task IDs, image IDs, copied questions, answer options, final answers, raw chart values, and evaluation-set provenance.

Any match rejects the entire candidate batch before promotion.

State transitions

ACCEPTED_V000 → KAPPA_FROZEN → COLLECTING → EPISODE_SNAPSHOT_FROZEN → CONSOLIDATING → CANDIDATE_FROZEN → PROMOTING → ACCEPTED | REJECTED → FINAL_FROZEN
Access checks, not design questionsExact Crusoe endpoint IDs, quotas, image payloads, and MemMachine record APIs are recorded during phase zero. The adapters absorb those values without changing the experiment.
